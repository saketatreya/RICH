A slow step says how long it has been slow

Drafting an architecture is one bounded model call and takes minutes; the button said "Designing…" for all of them, indistinguishable from a hang. Now an elapsed count and an honest range — no progress bar, because RICH has no estimate and a bar over an unknown duration is a lie. Kept

The architect's four-layer cap

It is a choice, not a limit — the compiler's ordering is general and would carry a deeper graph today. It is also what took first-attempt assembly from 0/6 to 6/6. Growth belongs at the pack boundary.

Reversed

Retiring v1 would have cost the canvas

The census said delete it. Acting on that would have deleted the React Flow canvas with it, so v2 got the graph first — then v1 came out having lost nothing.

Kept

models keeps its own path check

An explicit layering rule says it imports no sibling. Weakening that to fit a refactor was the wrong trade, so the duplication is intentional and says so in the code.

Kept

The unwired OpenAI adapter

A seam with one implementation is not a seam. It stays until a conformance suite can prove the claim — which is the card in Next, not a promise.
