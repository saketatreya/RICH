The seventh M4 live drive built the example again and then failed on the cost panel for a second, deeper reason: nothing was untouched. All three components came back `directly_stale` and `contract_changed`. The change compilation was telling the truth — both architectures came from the deterministic planner, which allocates *every* requirement to *every* layer, because that is what a layered decomposition means. Under it no component can ever be untouched by an amendment, so the drive was asserting something the shape cannot provide. The fallback is not the customer's path either: Maya approves a design the architect drafted. The drive now uses "Draft with the architect →" for both designs, which is the only path where change locality is observable and the only one the incremental redraft was built for. This is also, precisely, the argument for M13.
