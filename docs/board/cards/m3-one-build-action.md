Prepare, scaffold and execute stay three durable authority boundaries; the canvas runs them as one Build with derived defaults — destination from the project id and run, package scope from the project — and shows the three as a checklist while it waits. The budget is one dollar figure; the dimensions derived from it are shown, not hidden.
